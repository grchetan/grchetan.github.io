A modern, high-performance, responsive portfolio web application built with **React 19**, **TypeScript**, **TanStack Router**, **Tailwind CSS v4**, and **Firebase**.

---

## ✨ Features

- **⚡ Blazing Fast Performance:** Powered by Vite & React 19.
- **🎨 Glassmorphism & Modern UI:** Smooth micro-animations, dark mode support, and custom interactive themes.
- **🏆 Arcade & Signal Rush Game:** Integrated interactive arcade game with real-time score tracking & certificate generation.
- **🔒 Admin Control Center:** Private dashboard for content, credentials, blog posts, and visitor traffic management.
- **📱 Fully Responsive:** Optimized for all screen sizes from mobile to ultra-wide displays.
- **🔍 SEO & Analytics:** Meta tags, OpenGraph data, Google Search Console, Google Analytics (GA4), and Schema.org JSON-LD structured data.

---

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, TanStack Router, TanStack Query
- **Styling:** Tailwind CSS v4, Lucide React Icons, Motion (Framer Motion)
- **Backend / Services:** Firebase (Auth, Firestore, Storage)
- **Deployment:** GitHub Pages (Automated via `gh-pages`)

---

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/grchetan/grchetan.github.io.git
   cd grchetan.github.io
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
